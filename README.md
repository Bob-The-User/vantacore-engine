# VantaCore Engine

> Zero-knowledge memory forensics platform — open-source CLI & core library.

VantaCore Engine is a CLI tool and Python library for forensic analysis of raw DRAM dumps, ELF64 core dumps (including Cisco ASA `lina` coredumps), and network/security appliance memory images.
